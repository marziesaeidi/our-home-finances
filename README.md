# خانه ما

وب‌اپ موبایل‌محور مدیریت مالی مشترک، با رابط فارسی و راست‌به‌چپ.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخهٔ آمادهٔ انتشار:

```bash
npm run build
```

اطلاعات نمونه در اولین اجرا بارگذاری می‌شوند و تغییرات در `localStorage` همین مرورگر می‌مانند. افزودن تراکنش صفحهٔ مستقلی دارد و ثبت هزینه، درآمد، انتقال، پس‌انداز، وام و قسط از آن در دسترس است. برای تراکنش می‌توان عنوان دلخواه و یکی از ۱۰ آیکن را انتخاب کرد؛ پس‌انداز نیز عنوان دلخواه و هدف اختیاری دارد. روی تصویر عضو در بالای صفحه بزنید تا نمایش مرزیه و علی را عوض کنید. مرزیه در رابط، مدیر اصلی و تنها سازندهٔ لینک دعوت است. این نسخه ورود کاربری، کنترل دسترسی امن، همگام‌سازی بین دستگاه‌ها یا پذیرش دعوت واقعی ندارد؛ برای این قابلیت‌ها به سرور و پایگاه داده نیاز است.
