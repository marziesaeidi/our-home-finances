# SQLite محلی

نیازمند Node.js 24 یا بالاتر است. SQLite از ماژول داخلی `node:sqlite` استفاده می‌کند و نصب سرویس جداگانه لازم ندارد.

```powershell
npm run database:init
npm run database
```

در ترمینال دوم `npm run dev` را اجرا کنید. در تنظیمات برنامه، «ذخیره نسخه در SQLite» تمام اطلاعات مالی اعتبارسنجی‌شده فعلی را ذخیره می‌کند. فایل واقعی دیتابیس `data/khaneh.sqlite` است و وارد گیت نمی‌شود.

این مرحله SQLite را برای نگهداری نسخه‌های کامل داده متصل می‌کند؛ ذخیره اصلی روزمره و بازیابی برنامه همچنان از localStorage است. انتقال خودکار داده مرورگر و جایگزینی ذخیره اصلی انجام نمی‌شود. مبالغ، تاریخ‌ها، شناسه‌ها و تاریخچه بدون بازنویسی معنای مالی در JSON داخل جدول SQL نگهداری می‌شوند. هر ثبت نسخه جدید می‌سازد؛ نسخه‌های قبلی حذف نمی‌شوند. تراکنش SQLite و شماره نسخه مانع جایگزینی هم‌زمان داده می‌شوند.

`GET /api/database` آخرین نسخه را می‌خواند. `PUT /api/database` بدنه `{ "revision": 0, "data": ... }` می‌گیرد؛ revision باید نسخه دریافتی از GET باشد. داده نامعتبر رد می‌شود. پورت 8789 فقط روی 127.0.0.1 گوش می‌دهد؛ این سرویس برای انتشار عمومی یا چندکاربری آماده نشده است.

برای پشتیبان فایل، ابتدا سرویس را متوقف کنید و سپس فایل دیتابیس را کپی کنید. هنگام اجرا فایل‌های WAL نیز بخشی از وضعیت پایدارند. داده دیتابیس مانند پشتیبان JSON رمزگذاری نشده است.
