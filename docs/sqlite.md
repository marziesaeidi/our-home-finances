# SQLite

نیازمند Node.js 24 یا بالاتر است. SQLite از ماژول داخلی `node:sqlite` استفاده می‌کند و نصب سرویس جداگانه لازم ندارد.

```bash
npm run build
npm start
```

`server/app.mjs` برنامه، API و ورود کاربران را روی یک پورت (پیش‌فرض ۴۱۷۳، متغیر `PORT`) ارائه می‌کند. مسیر فایل دیتابیس با `DATABASE_PATH` تعیین می‌شود (پیش‌فرض `data/khaneh.sqlite`) و وارد گیت نمی‌شود.

جدول‌ها: `users` و `sessions` (فقط هش رمز و هش توکن نشست ذخیره می‌شود)، `spaces` و `space_members` (فضای شخصی یا مشترک و عضویت هر کاربر)، `space_snapshots` (نسخه‌های کامل و اعتبارسنجی‌شدهٔ داده هر فضا، فقط افزودنی)، `invitations` و `join_requests`.

همهٔ مسیرهای `/api/spaces/<id>/...` عضویت کاربر واردشده را بررسی می‌کنند؛ فضایی که کاربر عضو آن نیست، مثل فضای ناموجود پاسخ ۴۰۴ می‌گیرد. نوشتن با مقایسهٔ نسخهٔ قبلی انجام می‌شود و تغییر هم‌زمان دستگاه دیگر را بازنویسی نمی‌کند.

برای پشتیبان فایل، ابتدا سرویس را متوقف کنید و سپس فایل دیتابیس را همراه فایل‌های WAL کپی کنید. داده دیتابیس رمزگذاری نشده است؛ دسترسی به فایل را محدود نگه دارید.
